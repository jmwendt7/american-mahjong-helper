# American Mahjong Hand Finder

Static single-page tool: enter your exposed sets and rack, see which hands on your card are still possible and how many tiles away each is. Open `index.html` (or host on GitHub Pages).

The official NMJL card is copyrighted and changes yearly, so it isn't included. The page ships with original example hands; paste your own card into the "Card definition" box (format documented on the page). Card and tiles are saved in `localStorage`.
