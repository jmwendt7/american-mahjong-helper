Card definition

The NMJL card is copyrighted and changes every year, so it is not bundled. The hands below are original examples; replace them with your own card, one hand per line:
Name | points | pattern  with pattern groups count:tile.
Tiles: 1a–9c (number + suit letter; a/b/c are three different suits), $a = any number, $+1a = that number plus 1, F flower, wN wE wW wS winds, dG dR dW dragons, da = dragon matching suit a. Use # for comments. Jokers can fill any group of 3+.
